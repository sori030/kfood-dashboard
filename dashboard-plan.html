📊 업데이트 스케줄 (주 1회)

매주 월요일 Xpoz MCP로 SNS 5개 채널 수집 실행 ~25 크레딧
수집 직후 인사이트 정리 → 대시보드 데이터 갱신 자동
월요일 오후 주간 콘텐츠 기획 → 채널별 초안 생성 AI
크레딧 예측 5,000 크레딧 ÷ 25 = 약 200회 → 약 4년치 여유 충분

🚀 GitHub 배포 구조

GitHub Pages로 정적 배포 → URL 공유만으로 팀원 접근

비공개 저장소(Private Repo) → 내부 관리용 보안 유지

HTML + CSS + JS만 사용 → 서버 불필요, 무료 운영

JSON 파일로 데이터 분리 → 데이터만 교체해서 화면 갱신

팀원은 GitHub Collaborator 추가 → 편집 권한 부여
